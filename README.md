# Get started
Install dependicies:
- pytorch
- python 3.13+
- numpy
- gradio (for gui)
- matplotlib Pillow (library for gui code)

Run the following commands in terminal: (need to install python first)

- pip install torch 
- pip install numpy
- pip install gradio
- pip install matplotlib Pillow
